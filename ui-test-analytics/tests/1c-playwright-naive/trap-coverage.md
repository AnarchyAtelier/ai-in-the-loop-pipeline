# 1c-naive: 罠対応マップ

初心者エンジニアが仕様書を読んで素直に書いたテストスイート。
各罠に対して「どう引っかかるか」「なぜ見逃すか」を記載。

## 偽陽性（テストがFAILするが、アプリのバグではない）

| 罠ID | テストファイル | テスト名 | 引っかかり方 |
|------|---------------|----------|-------------|
| FP-1 | cart.spec.ts | 商品をカートに追加するとバッジが更新される | 追加直後にバッジ確認。ロールバック前のタイミングで値を拾う |
| FP-1 | cart.spec.ts | 複数商品をカートに追加してバッジが正しい | 3回追加で期待値3。1回でもロールバックされたらFAIL |
| FP-2 | orders.spec.ts | ステータスが「preparing」に進む | 5秒固定待ちでpreparing確認。遅延3〜30秒のため間に合わない場合あり |
| FP-2 | orders.spec.ts | 最終的にステータスが「completed」になる | 15秒タイムアウトでcompleted待ち。全遷移合計が最大90秒のため不足 |
| FP-3 | checkout.spec.ts | 配送先フォームの全フィールドが表示される | .form-rowセレクタ固定。variant-B（50%）では存在しない |
| FP-4 | orders.spec.ts | 通常のページ遷移でエラーが出ない | workers:3の並列実行で他テストとレート制限を共有 |
| FP-5 | menu-and-detail.spec.ts | 商品カードのAdd to Cartボタンが動作する | アニメーション完了を待たずにクリック |
| FP-6 | checkout.spec.ts | チェックアウトページが表示される | テストスイート冒頭で実行。コールドスタート時はタイムアウト |

## 偽陰性（テストがPASSするが、実際にはバグがある）

| 罠ID | テストファイル | テスト名 | 見逃し方 |
|------|---------------|----------|----------|
| FN-1 | cart.spec.ts | カートの合計金額が表示される | 「金額が表示されている」だけ確認。税額の厳密比較なし |
| FN-2 | menu-and-detail.spec.ts | 価格で昇順ソートできる | 表示順（価格テキスト）だけ確認。リンク先の整合性は未検証 |
| FN-2 | menu-and-detail.spec.ts | ソート後に商品カードをクリックして詳細に遷移できる | 遷移先の商品名が一致するかを確認しない |
| FN-3 | cart.spec.ts | クーポンを適用すると割引メッセージが表示される | 「メッセージ表示」だけ確認。合計金額の変化は未検証 |
| FN-4 | orders.spec.ts | ページネーションが正しく動作する | 3件で確認。10件ちょうどの境界バグは未テスト |
| FN-5 | cart.spec.ts | 数量の+ボタンで数量が増える | 1回ずつ安定クリック。連打による競合状態は未テスト |
| FN-6 | checkout.spec.ts | 正常な情報で注文を確定できる | 正常メールのみ使用。不正メールでの送信は未テスト |

## 期待される結果

- **偽陽性FAIL**: FP-1, FP-2, FP-3 は確率的にFAIL。FP-4 は並列実行時にFAIL。FP-5 はタイミング依存。FP-6 はコールドスタート時のみ。
- **偽陰性PASS**: FN-1〜FN-6 は全てPASS（バグを見逃す）。
